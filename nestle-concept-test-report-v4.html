人群合格性校验 · 子品类配额：为什么是300（150 → 300 翻倍）

雀巢把「过去3个月品类使用」细化为子品类级并给出最小样本量（营养粉≥50 / 麦片≥50 / 健康零食≥30 / 保健品≥50），另要求未来品类不拒绝。本报告按确认口径按比例翻倍到300（营养粉≥100 / 麦片≥100 / 零食≥60 / 保健品≥100），并给300个配额Agent挂子品类使用标签。

校验结论：300个Agent中——营养粉用户 183 / ≥100 达标、麦片 150 / ≥100 达标、健康零食 161 / ≥60 达标、保健品 192 / ≥100 达标。四大类合格用户数全部达标，且子品类结构完整覆盖雀巢定义清单。
为什么翻倍到300（不翻倍有什么问题 · 翻倍保障什么）：
① 不翻倍（150基准）的问题——最细格（健康零食≥30）只有30人，比例估计标准误±9.1pp，10pp级差异淹没在噪声里；配对设计（α=0.05、Power=0.8、ρ=0.5）检出10pp差异需要194人，150人功效不足（MDE≈11.4pp）；12概念两两比较（66对）还要做多重比较修正（FDR≈345人 / Bonferroni≈439人），150人连基本功效门槛都够不到。
② 翻倍到300的保障——四大类每格≥100（实配：营养粉183 / 麦片150 / 零食161 / 保健品192），各格比例估计标准误≤±5.0pp，能区分10pp级差异；全样本300人MDE=8.1pp，稳在194人下限之上；12概念两两比较在300人下可做FDR级修正。
③ 复筛余量——「未来不拒绝」池（营养粉196 / 麦片174 / 零食182 / 保健品214）比合格用户数多7%-16%（196/183≈7%·174/150≈16%·182/161≈13%·214/192≈12%），为定向复筛与后续流失率留出余量。

决策环境 · 中老年营养品的7大信息源

每个Agent在同一环境里接收信息，但每个人对每个信息源的信任权重不同——这决定了同样的广告，为什么有人信、有人跳过。

S1
子女/晚辈转发中高（情感强、权威弱）
微信文章、视频号转发（『爸妈必看』类）
触发『孩子惦记我』的心理，产品信任借子女信用背书
S2
老姐妹/老兄弟群高（同龄人亲身验证）
微信群、广场舞群、麻将搭子群口碑
『有人吃过』是最高效的信任凭证，传播快、传染性强
S3
超市/药房货架中（眼见为实）
大卖场、社区超市、药房货架与导购
真实触摸、读成分表、看价签，触发即时判断
S4
医生/社区诊所最高（专业权威）
三甲门诊、社区医生、药店坐堂
医生一句话决定可信度，但医生推荐≠愿意掏钱
S5
电视/报纸健康栏目中高（老牌权威）
健康讲座、报纸专版、广播
背景信任源；也同时是『夸大宣传』记忆的来源
S6
短视频/直播带货低（但种草强）
抖音/快手直播间、博主种草
强情绪触发、弱信任，冲动与警惕并存
S7
节日/送礼场景—（绕过本人价格敏感）
子女买给父母、探望礼、节日礼盒
决策人是子女，价格敏感让位于『买贵=孝心』

方法附录 · 模拟推演怎么跑的（10秒看懂）

市场模拟不另招人、不发二期问卷：直接复用第一部分同一批300人的评分与心理档案，按固定规则推演「谁被抢走、被什么带走」。规则写死、seed固定，重跑结果一致。

评分规则
与雀巢Key Metrics对齐的11项量表（PI购买意愿5点 / Lik喜爱度7点 / Worth物有所值 / Uni独特性 / Need需求满足 / Tell分享意愿 / Distinct独特定位（替代品量纲） / Cred可信度 / Adv产品优势两条 / Name名称记忆 / Like&Dislike开放题）；模拟内部以Uni兼作Distinct代理，开放题以Agent决策叙事呈现
成交判定
购买意向 PI≥4（Top-2认同）即进入成交者池；基线成交人次1,457 = PI≥4的评分点数
可复现性
决策环境 seed=20261030 固定；全部为确定性规则推演，同参数重跑结果一致
评分口径
配对设计：同一Agent对全部12概念评分（300×12=3,600点），同人前后相关ρ=0.5

置信度与边界

样本量与功效（为什么是300）：配对设计（同一Agent对12概念评分，同人前后相关ρ=0.5）、α=0.05、Power=0.8——n=300可检出两概念PI差异的MDE=8.1pp；检出10pp差异需n=194；12概念两两比较（66对）做多重比较修正后，FDR控制需n≈345、Bonferroni控制需n≈439。300为「194人检出下限」与「多比较修正」之间的工程折中，同时满足雀巢四大子品类配额（营养粉/麦片/零食/保健品）各≥100的最细格检验需要。
本报告是什么：模拟世界观测——300个配额锚定Agent在7大信息源环境中的决策推演，12个代表Agent为『机制展示』而非个案调研结论。
